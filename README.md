# Community Connect — Oregon Prototype

A mobile-first React prototype for a searchable directory serving the Ethiopian community in Oregon.

## What is included

- Home page with four directory categories
- Category pages for jobs, caregivers, services, and products
- Keyword search and category-specific filtering
- Oregon city filter and newest/title sorting
- Listing detail modal
- Simulated post-listing form
- Responsive mobile navigation and filter panel
- Fictional sample listings only

## Important prototype limitations

This is a front-end demonstration, not a live marketplace.

- No backend, database, authentication, or persistence
- The post-listing form does not save or publish submissions
- Contact details are intentionally not included
- All listings and organization names are fictional examples
- The category counts are illustrative, not real community statistics

Do not enter real personal, contact, or sensitive information into the demo form.

## Run locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Suggested validation next steps

1. Test the prototype with 5–10 community members.
2. Observe whether they can find a relevant listing without help.
3. Ask which filters or categories are missing.
4. Share the demo with group admins before wider distribution.
5. Measure actual demo usage and willingness to submit listings before building a backend.
